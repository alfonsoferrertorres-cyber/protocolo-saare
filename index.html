Modalidades de Integración Comercial

Diseñado para adaptarse a las necesidades de distribución de cualquier fabricante de software (ISV).

1. Dynamic Library Integration

Vinculación dinámica mediante `saare_runtime.dll` / `.so` para software compilado en C++, C#, Go o Rust.

2. Embedded Python Wrapper

Importación directa del paquete `saare_sdk.py` en entornos de inteligencia artificial, PyTorch y LangChain.

3. Standalone CLI Gateway

Ejecución del binario `saare-runtime.exe` como demonio perimetral o sidecar en entornos Kubernetes.

4. Rust Crate Dependency

Inclusión directa de las crates de la workspace en el archivo `Cargo.toml` de aplicaciones cliente.
